# About This Site

This is whiteleibniz's personal technical blog. It collects technical write-ups and troubleshooting retrospectives on embedded development, system porting, emulators, and multimedia.

Topics covered:

- **Embedded hardware**: Mali GPU, VSP hardware decoding, display and wireless drivers
- **System porting**: bionic/musl cross-compilation, Alpine chroot, build-chain compatibility
- **Troubleshooting notes**: root-cause analysis of real issues and methodology summaries
- **Tooling**: self-built debugging and deployment toolchains
