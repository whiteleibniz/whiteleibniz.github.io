AI 工作流归档

本目录归档 AI 协作过程中每次任务的最终可交付产物，按业务目标拆分子目录。
规则：只收”能直接部署运行、达到结果”的最终产物（交付文档 / 最终服务源码 / 设备实际运行的部署脚本）；
过程用的临时脚本（部署调试、测试、诊断、探索类）一律不归档。

隐私红线（强制）

  • 项目公开：文档、git 备注、归档文件中禁止出现真实 SSH 密码、账号、真实 IP。
  • 一律使用占位符：<设备IP> / <WiFi-IP> / <密码>；真实凭据只在运行参数或环境变量中提供。

目录规范

子目录 内容
01_WiFi打通/ docs: 操作手册/流程对比/工作总结/AI指导手册/故障排查手册/部署交付文档；deploy: wifi.start（开机部署脚本）
02_蓝牙打通/ docs: 6份文档（含故障排查手册）；src: bt_user_daemon.c(最终服务源码)+bluetooth_page.c/h(LVGL界面源码)；deploy: bt_bringup.start/bt_daemon/bt_wake.sh(设备实际运行部署)
03_HT0可复用资产/ ht0-wcn-radio Skill 快照（SKILL.md + references + 可直接运行的运维脚本）
04_桌面应用框架/ docs: LVGL 桌面应用架构与第三方接入规范
05_收音机/ docs: FM 收音机规划与逆向文档（LVGL界面设计规格 / AI指导手册 / 操作手册 / 故障排查手册 / 原理与移植Wiki / 启动流程对比 / 部署交付文档 / 工作过程总结 / ioctl命令表逆向还原）；src: fmprobe.c（ioctl 实测探针，已验证 45/47）；fm_user_daemon.c（待实装）
bugfix/ 每次 bug 修复的说明文档（现象/根因/定位/解决/验证），索引见 bugfix/README.md

新增业务目标时按 NN_业务名/ 递增编号，docs / src / deploy 视需要拆分。

文档同步协议（版本化，打 tag 时同步）

文档不随每次迭代提交更新，按版本定版（打 tag）统一同步：

  1. 日常迭代：只提交代码 / 脚本 / 配置改动，备注写清改动内容；不动文档。
  2. 打 tag 定版（用户确认功能完善 / 稳定）时，一次性同步：
    • 对应任务 docs/ 文档族（操作手册 / 故障排查手册 / AI指导手册 / 部署交付文档 / 流程对比 / 工作总结）+ Skill 资产（SKILL.md、references/、scripts/）
    • 文件增删改名时更新本 README 目录规范
    • 校验：文档中命令 / 路径 / 产物与设备实际运行状态一致（改过的层须实测过）
    • 打 tag：git tag <vX.Y.Z>，备注中文，写明「定版范围 + 同步更新的文档清单」
  3. tag 提交包含或紧随文档更新，保证「一个 tag = 一份完整文档快照」可回溯。
