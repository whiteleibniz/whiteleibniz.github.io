需求：把「原廠桌面」改為「切換桌面」+ 橫屏放大式滑動菜單

日期：2026-09-24　狀態：已編碼並部署到設備（待用戶手驗）

決策記錄（2026-09-24 15:00）：Q1 選 方案 A（整屏旋轉 90°）；
Q2/Q3/Q4 按默認走 —— 原廠桌面入口去掉 / 菜單含全部應用 / 買單鍵回豎屏桌面。

1. 現狀（已核實）

項 事實
桌面實現 lv_pages/launcher_page.c（1255 行），s_apps[] 靜態表 19 項 + 外部應用 /usr/local/lvgl/apps/*/app.ini
「原廠桌面」表項 第 118 行 { LAUNCHER_APP_FACTORY_DESKTOP, "原廠桌面", LV_SYMBOL_HOME, 0x16a085 }
現狀行為 launcher_restore_factory_launcher() → umount 掉 upgtool 的 bind mount → exec /usr/bin/launcher（原廠安卓桌面）
參考實現 /home/lvgltest/wxbUI/my_launcher_img/my_launcher/launcher_ui.c（256 行，1280x720 橫屏，每頁一個大卡片 520px，左右翻頁，JPEG 圖標）
屏幕 720x1280 豎屏（32bpp），物理鍵：點餐=114(LEFT)、服務=102(RIGHT)、福利=115(ENTER)、買單=116(BACK)

2. 需求拆解

R1 表項改名 + 改行為
s_apps[] 裡「原廠桌面」→「切換桌面」；點擊後不再 exec 原廠 launcher，改為切到橫屏放大菜單模式。

R2 橫屏放大菜單（coverflow）

  • 邏輯上一排卡片：中間 1 個選中（放大 1.6x，不透明），左右各 1 個正常大小（1.0x，半透明 ~0.6），更遠的隱藏。
  • 左右鍵導航時帶動畫：位置 + 縮放同步過渡，400ms 緩動（cubic-bezier(.22,.61,.36,1)）。
  • 菜單項 = 現有桌面全部應用（含外部應用），沿用現有圖標符號 + 背景色，不新增圖片資源。

R3 雙向切換（toggle）

  • 豎屏網格桌面 → 點「切換桌面」→ 橫屏放大菜單
  • 橫屏放大菜單 → 點同一項「切換桌面」→ 回豎屏網格桌面

R4 鍵位

鍵 橫屏菜單模式下
點餐 114 / LEFT 選中上一項（帶動畫）
服務 102 / RIGHT 選中下一項（帶動畫）
福利 115 / ENTER 啟動選中應用
買單 116 / BACK 回豎屏桌面（建議，待確認）

R5 不改的地方
默認豎屏網格桌面的佈局、焦點導航、外部應用加載、重啟/關機確認彈窗，全部保持現狀。

3. 需要你拍板的 4 件事

Q1（最關鍵）橫屏怎麼呈現？

方案 A：整屏旋轉 90° 方案 B：豎屏內橫向放大帶
做法 容器按 1280x720 佈局，transform_rotation=900 旋到豎屏 不旋轉，圖標橫排在 720 寬的屏幕中部
卡片大小 最大（300~520px） 中等（選中 ~272px，兩側 170px）
左右鍵語義 屏幕上下移動（反直覺，需把機器橫過來看） 屏幕左右移動（直覺一致）
性能 旋轉後每幀全屏重繪，768MHz 軟渲染有掉幀風險 只重繪中間帶，開銷小
實現量 需處理旋轉後的座標/焦點/觸摸換算 純絕對定位 + 動畫

建議：方案 B（機器豎裝、鍵位語義一致、性能好；放大效果完全一樣）。

Q2 原廠桌面的入口還要不要？

改成「切換桌面」後，原廠安卓 launcher 就沒有入口了。

  • 選項①：徹底不要（推薦，原廠桌面在 LVGL 桌面上基本用不到）
  • 選項②：保留，移到「設置」頁里加一個「啟動原廠桌面」按鈕

Q3 橫屏菜單裡放幾個應用？

  • 選項①：全部（19 項 + 外部應用），滑動較長
  • 選項②：只放常用 N 項（你指定）

Q4 買單鍵（BACK）在橫屏菜單裡做什麼？

  • 選項①：直接回豎屏桌面（推薦）
  • 選項②：無效，只能靠選中「切換桌面」回去

4. 實現要點（確認後按此編碼，不新建頁面）

  1. 不新建頁面，在 launcher_page.c 內加模式態（網格模式 / 橫屏菜單模式），避免頁面棧與焦點組進出不成對的問題（既有教訓：焦點組共享，進出必須成對）。
  2. 動畫：lv_anim 同時驅動 x 與縮放；縮放優先用 lv_obj_set_style_transform_scale（整體縮放，圖標符號跟著放大，不用改字號）；不依賴 flex 重排，全部絕對定位。
  3. 性能：只創建/顯示 3 個可見卡片，其餘加 LV_OBJ_FLAG_HIDDEN；動畫期間不觸發整屏重繪。
  4. 回退：網格桌面的對象在橫屏模式下隱藏而非銷燬，切回時不重建，避免狀態丟失。
  5. 改完走既有部署流程（make -j2 → 原子替換 → 重啟），驗證由你手驗。
